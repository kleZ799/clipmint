# Exact versions the release builds install, passed to pip with -c.
#
# The requirements files say what the app needs; this says what it ships with.
# Without it release.yml installs the newest version each range allows, so an
# upstream release nobody has run lands straight in the exe: v1.24.1 picked up
# PyAV 19 and failed every transcription while the source checkout, still on
# 18, worked fine.
#
# Taken from the v1.24.2 builds on all three platforms. A package one platform
# never installs is ignored there, so one file serves Windows, macOS and Linux.
#
# Two packages are left out on purpose and float to their newest version:
#   yt-dlp   -- YouTube breaks old versions; a release should carry the latest.
#   certifi  -- the CA bundle; newer is only ever more correct.
#
# To move a pin: change it here, push a tag, and run the build before trusting it.
