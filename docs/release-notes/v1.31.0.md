Ollama joins the AI providers, so ClipMint can pick your clips with a model on
your own computer: no key, no account, nothing uploaded. Asked for on GitHub
([#20](https://github.com/kleZ799/clipmint/issues/20)).

## Ollama, for running with no key

1. Install [Ollama](https://ollama.com/download).
2. Pull a model. In a terminal: `ollama pull qwen3:8b` (about 5 GB).
3. In ClipMint, open **Settings → Model**, pick **Ollama**, and press
   **Use Ollama**.

That is all. Settings lists the models you have pulled, with their size and
whether they can see frames, and you can switch between them there. If Ollama
runs on another machine, put its address in the box beside it; empty means
this computer.

- **Text and frames both work.** Ranking uses the model you pick. Checking each
  clip's opening shot needs a model that can see, such as `qwen2.5vl:7b` or
  `gemma3`. If the one you picked can't, ClipMint uses another pulled model
  that can, then any other provider you have set up, and otherwise skips that
  check.
- **It runs with a long enough memory.** Ollama gives a model a 4k-token window
  unless asked for more, and cuts the start of anything longer without saying
  so. ClipMint asks for 16k, so the instructions at the top of each request are
  not the part that gets lost. `OLLAMA_NUM_CTX` changes it.
- **It is on the fallback ladder** after the free cloud providers and before the
  paid ones, but only if you have chosen a model for it. Having Ollama installed
  for something else does not make ClipMint use it.

Be realistic about what to expect: a model that fits an 8 GB GPU picks clips
less well than Gemini or Claude, and a long video takes a while, longer still
without a GPU. It is the choice for privacy, offline use, or no key, not for
the best picks.

This is new and I could only test it against a stand-in server, not a real
model. If it misbehaves with yours, [tell me](https://github.com/kleZ799/clipmint/issues/new/choose)
which model and what happened.
