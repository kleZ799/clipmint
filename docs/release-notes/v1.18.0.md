Upload a whole run to YouTube in one go, scheduled a day apart or however you
like, without opening every clip.

## Upload all

Every run in **Your clips** now has an **Upload all** button, next to
**Rewrite titles**. It opens a list of every clip in that run:

- **Each clip's title, description and tags**, ready to check and edit. Your
  edits are saved to the clip.
- **A tick box** to include or skip each one. Clips already on YouTube start
  unticked.
- **One choice for the whole batch:** scheduled, public, unlisted or private,
  plus the category and YouTube's made-for-kids question.
- **Scheduling that spaces them out:** pick when the first goes public, then
  one every 3, 6 or 12 hours, every day, or every 2 days. Each clip shows its
  own publish time before you upload.

Press **Upload N clips** and they go up one at a time while you keep working.
Every row shows where it's at: waiting its turn, uploading, then scheduled or
live. Closing the list doesn't stop them.

If YouTube says your channel has uploaded as much as it can for the day, the
remaining clips stop straight away with that message, instead of each one
trying and failing. Run them again tomorrow.

Uploaded clips now show an **on YouTube** tag in the grid.

## Fixes

- The **Upload to YouTube** button under Boost no longer touches the
  Rewrite / Save / Copy buttons below it.
- If the Google client ClipMint signed in with goes missing, Settings no
  longer says YouTube is connected. That would have offered an upload that
  could only fail.

**ClipMint.exe**: about 220 MB, Windows, self-contained. Unsigned, so
SmartScreen will warn: **More info → Run anyway**.

**ClipMint-linux-x86_64**: about 278 MB, x86-64, self-contained, glibc 2.35 or
newer. `chmod +x` it and run it. **Still untested on a desktop distribution.**
Every published build is started by the release workflow and asked for its
interface before the release exists, but nobody has yet made a Short with it
on Fedora or Ubuntu. Take `ClipMint-linux-README.txt` too.

**ClipMint-macOS-arm64.zip**: about 165 MB, Apple Silicon only. **Still a beta,
and still has never been run on a Mac.** I don't own one, so it is built and
checked by GitHub's macOS runners and published without a person opening it.
Uploading to YouTube has only been tested on Windows. If it doesn't start, or
signing in doesn't behave as described, that is a bug here:
`~/Movies/ClipMint/app.log` and
[an issue](https://github.com/kleZ799/clipmint/issues/new) are how it gets
fixed.

Also published, for installs from before the rename only: `StreamToShorts.exe`,
`StreamToShorts-linux-x86_64` and `StreamToShorts-macOS-arm64.zip`, the same
three files under their old names. A fresh download wants the ClipMint ones.

On v1.5.0 or later on Windows, or on any Linux build? The app will offer this
to you.
