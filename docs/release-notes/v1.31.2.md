One small thing, asked for by someone who posts a lot of clips.

## Copy description, on every card

In **Your clips**, each card now has **Copy description** beside **Copy title**
and **Copy tags**. Before, the description could only be copied from inside the
clip, so posting a batch by hand meant opening every one of them. Now it's one
click per clip, straight from the grid.

It shows on any clip that has a description written. A clip without one gets
**Write it now** in the player, same as before.

Thanks to the person who sent a screenshot with the button drawn on in red.
That's the clearest feature request I've had.
