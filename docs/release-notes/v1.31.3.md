Two fixes, both reported this week.

## "Error code: 401, Incorrect API key" with Gemini selected

Some runs stopped at **Ranking** with an OpenAI error, `Incorrect API key
provided: AQ.Ab8…`, even with **Google Gemini** chosen in settings. Swapping the
Gemini key didn't help, because the Gemini key was never the problem.

What happened: Gemini was busy, so the run moved on to the next model you'd set
up, which was OpenAI. The key saved for OpenAI was actually a Gemini key, pasted
there by mistake while OpenAI was selected. OpenAI refused it, and that was the
only error you saw.

Now:

- **A key pasted under the wrong provider is caught when you save it.** Paste a
  Gemini key with OpenAI selected and it tells you to choose Google Gemini
  instead.
- **A key already saved in the wrong place is skipped**, and the log says so.
- **OpenAI failing no longer ends the run.** It moves on to the next model you
  set up, like Groq and the others always did.
- **The error says what happened first.** If every model fails, you see why
  each one stopped, not just the last.
- **Spare Gemini keys** now accept Google's newer keys that start with `AQ.`.

If you hit this: update, then open **Settings** and press **Generate** again.
If a key is in the wrong place, the message tells you which one.

## Clips that came out black, with only sound

A video whose picture stops before its sound does (a recording where the video
cut out, or an export with a long audio-only ending) could get clips picked from
the part with nothing to see. Those came out as a black screen with sound.

Clips now only come from the part of the video that has a picture, and the log
says where the picture stops. If a clip still comes out with no picture, the
run says so instead of handing you a black file.
