## Phone videos render again

Some videos stopped before the first clip with `could not probe source
(invalid literal for int() ...)`, whatever resolution you picked. ClipMint
reads a video's width and height before cutting anything, and on some files the
answer came back broken across lines, so the size couldn't be read. Changing the
settings couldn't help, because this happens before any of them are used.

Videos filmed on a phone held upright had a second problem. The phone saves the
picture sideways with a note saying "turn this 90°". ClipMint read the sideways
size, but the video is turned upright when it's played back, so the crop was
worked out for the wrong shape and the render failed.

Both are fixed: the size is read in a format that can't break that way, and an
upright phone video is measured the way it's actually shown.

Thanks to the person who emailed the exact error. That made it quick to find.
