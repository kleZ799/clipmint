Two fixes found while retaking the screenshots for v1.14.0, and a clearer way
to run the app from source.

## Several exact cuts in one prompt work again

Naming more than one timespan in a prompt could scramble everything written
after them. *"cut 47:02 to 47:34, 1:31:16 to 1:31:46, … , gameplay only"* with
five spans came out with the webcam stacked on top, in 4:5, as if *gameplay
only* had never been typed. The spans themselves were cut correctly; it was the
rest of the prompt that got mangled. One span was always fine. Now any number of
spans leave the rest of the prompt exactly as you wrote it.

## The Instagram Reels tab shows its whole name

In **Boost**, the middle tab read *"Instagram Re…"*. The tabs now size to their
names. The note about Instagram's 125-character fold also no longer sits on top
of the caption options below it.

## Running from source: a requirements file per platform

Nothing changes for the downloadable app. If you run from source, there is now a
file for each platform — `requirements-windows.txt`, `requirements-mac.txt`,
`requirements-linux.txt` — each listing, at the top, what pip cannot install for
you. Add `requirements-nvidia.txt` for GPU transcription, or
`requirements-build.txt` to package the app yourself.

---

**StreamToShorts.exe** — about 220 MB, Windows, self-contained. Unsigned, so
SmartScreen will warn: **More info → Run anyway**.

**StreamToShorts-linux-x86_64** — about 278 MB, x86-64, self-contained, glibc
2.35 or newer. `chmod +x` it and run it. **Still untested on a desktop
distribution** — every published build is started by the release workflow and
asked for its interface before the release exists, but nobody has yet sat at
Fedora and made a Short with it. Take `StreamToShorts-linux-README.txt` too.

**StreamToShorts-macOS-arm64.zip** — about 165 MB, Apple Silicon only. **Still
a beta, and still has never been run on a Mac** — I do not own one, so it is
built and checked by GitHub's macOS runners and published without a human
opening it. If it does not start, that is a bug here:
`~/Movies/StreamToShorts/app.log` and
[an issue](https://github.com/kleZ799/stream-to-shorts/issues/new) are how it
gets fixed.

On v1.5.0 or later on Windows, or on any Linux build? The app will offer this
to you.
